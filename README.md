# AnchorVaultCoin — блог

Разборы реальных краж криптовалюты, простые объяснения и практические советы.

Сайт: https://anchorvaultcoin-hash.github.io/anchor-vault-blog/
Основной проект: https://anchorvaultcoin-hash.github.io/anchor-vault-frontend/landing.html

## Как добавить статью

1. Положить `.md` файл в `docs/posts/`
2. Запустить `python3 tools/blog_build.py`
3. Закоммитить и запушить

В начале файла указывается заголовок, описание, дата и адрес страницы.
Остальное собирается автоматически: HTML, список статей, RSS, карта сайта.
